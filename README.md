mend applies an edit written by an AI model (a unified diff, SEARCH/REPLACE blocks, a V4A patch or JSON text-editor calls) to a tree of text files, all or nothing. It finds the lines to change exactly, then ignoring trailing whitespace, then ignoring indentation, so edits with wrong line numbers or reflowed whitespace still land.

## Run it

```sh
node main.ts [options] [PATCH]
```
